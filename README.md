# Overview

This project is a simple task manager made with TypeScript. It allows users to add, view, complete, remove, and search for tasks. The program also saves tasks so they can be loaded again later.

I created this program to learn TypeScript and practice using classes, arrays, recursion, asynchronous functions, and exception handling.

[Software Demo Video](Work in Progress...)

# Development Environment

I used Visual Studio Code to write the program, Node.js to run it, and npm to install TypeScript.

The program was written in TypeScript. I also used the built-in Node.js file system and readline modules to save tasks and get user input.
